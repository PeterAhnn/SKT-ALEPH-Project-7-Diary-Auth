1. 오늘 관찰 계획의 Plan에서 실제 할 일 3개를 정해 등록한다. 실제로 한 것만 완료하고 하루를 마친 뒤 5일 탭에서 오늘 값을 확인·확정한다. 현재는 할 일 0개이며 제안한 예시를 실제 채택한 할 일로 만들지 않는다.
2. 서로 다른 한국 날짜에 2일차를 기록·확정한다. 공식은 연속 5일을 요구하지 않는다. 앱은 시작한 날짜에 1일차 확정을 요구하므로 시작일을 놓친 경우 새 관찰 계획으로 다시 시작해야 한다.

5. 5일 및 전후 합계·평균을 직접 계산해 화면과 대조하고 해석을 남긴다. 최종 전체 파일 하나를 다시 내보낸다. 실제 사용자 판단과 거절/없었던 이유를 보완한다.
6. 카드 1~5·완주 체크리스트·제출물·증거 보관/비밀값 가림·최종 공개 URL을 재대조한 뒤 제출하고 접수를 보관한다. 강사/마스터 승인은 접수와 구분한다.
