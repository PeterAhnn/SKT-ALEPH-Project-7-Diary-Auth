## 준비된 것

- 카드 1~4 코드·가린 실제 합성 성공/거절 근거와 여섯 항목 설명서.
- 사용자 답변 “선택과 검증을 마음대로 해서 직접 확인하고 수정함”을 설명서 ⑤와 판단 3줄에 반영. 구체 사례는 만들지 않았다.

- `scripts/prepare-submission.mjs FULL_COMMIT`: 고정 커밋에서 설명서/입력 문안을 읽고 선택 첨부 MD, 붙여넣기 TXT, 크기·SHA256·검사 범위 manifest를 생성한다. 상대 근거 링크는 해당 커밋의 공개 GitHub 링크로 바꾼다.

생성 파일은 Git에서 제외한 `.test-data/submission-prep/`에 보관한다. MD 한 파일만 선택 첨부 후보이며 TXT/manifest는 작업용이다. 실제 비공개 계정 export를 공개하거나 첨부하지 않는다. 별도 PDF는 필수가 아니다.
