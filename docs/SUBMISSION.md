# T07 제출 초안 · 미제출

2026-10-02 현재 로컬 인증 구현과 합성 검사를 마쳤다. 공개 배포·실제 자료 이관·실제 5일 사용·공개 소스 URL이 없어 **최종 제출 문안이 아니다**. T06 실제 제출 문안은 [T06-SUBMISSION.md](./T06-SUBMISSION.md)에 그대로 보존했다.

## 결과물 URL (필수)

미준비. 공개 HTTPS 주소와 새 시크릿 창에서 로그인 첫 화면까지 접근 가능한지 확인한 뒤 입력한다. 로컬 주소와 T06 결과 주소를 T07 결과물 URL로 제출하지 않는다.

## 소스 저장소 URL (필수)

미준비. `https://github.com/OWNER/REPO/commit/FULL_COMMIT` 형식의 실제 확인된 40/64자리 소문자 전체 커밋 URL을 입력한다. T07 Git 이력에는 T06 최종 제출 `b9de0298cd200961eac56286c6a6a55299947a96`가 조상으로 있다. 공개 GitHub 원격은 아직 없다.

## 인증 구현 설명서

[AUTH-IMPLEMENTATION.md](./AUTH-IMPLEMENTATION.md)의 여섯 항목은 현재 로컬 범위 설명과 실제 합성 검사 근거다. 공개 운영 검사와 T06 이관·실제 5일 근거를 연결한 뒤 최종화한다. 별도 PDF나 첨부 파일은 공식 필수가 아니다.

## 재현·통과 확인 4가지 (권장)

- 어디로 가나요: 최종 공개 주소 미준비. 현재 소스를 Node 24로 `npm start`하면 로컬 `127.0.0.1:8009`에서 확인할 수 있다.
- 무엇을 하나요(3단계 이내): ① 가입 후 로그인 ② 내 계획/할 일을 저장하고 새로고침 ③ 로그아웃 뒤 다이어리 주소 열기.
- 무엇이 보이면 통과: 로그인 후 내 계정 자료만 보이고 저장이 유지되며 로그아웃 뒤 로그인 화면이 나온다. 최종 제출에는 가린 양방향 거절·무변경·5일 집계 근거도 연결한다.
- 안 될 때: 로그인 없이 자료 API는 401, 다른 계정 자료는 404, 미구성 클라우드는 503. 오류 화면과 실제 기록을 보존한다. 최종 운영 안내는 배포 후 갱신한다.

## AI와 내 판단 3줄 (권장)

- AI에게 맡긴 일: 현재 코드 이력 연결, 인증·계정 분리 구현, 합성 자동/브라우저 검사, 공식 기준과 구현 설명 연결.
- 내가 판단한 일: 관찰 지표를 ‘완료한 할 일 수(개)’로 선택했다. 질문·첫 규칙·실제 기록 해석은 아직 미확정이다.
- AI 말을 안 들은 일: 사용자의 실제 거절 또는 그 이유는 아직 기록이 없다. ‘없다’는 사용자 확인 없이 만들어 쓰지 않고 최종 제출 전에 실제 판단을 기록한다.

## 확인 파일 선택 / 보관

첨부는 선택, 한 번에 10개·합계 8MB. 현재 업로드 없음. 합성 검사는 실제 기록으로 바꾸지 않고 비밀번호·token·cookie·CSRF 원문을 가린 상태로 보관한다. 공개 소스에 실제 비공개 사용자 export를 올리지 않도록 자료 범위를 최종 점검한다.
