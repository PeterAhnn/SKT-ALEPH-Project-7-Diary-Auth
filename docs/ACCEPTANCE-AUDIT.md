## 제출과 증거 보관

결과물은 공개 HTTPS 로그인 첫 화면, 소스는 공개 소문자 full commit URL이다. 인증 구현 설명서 여섯 항목을 제출 내용에 연결한다. 확인 4줄·판단 3줄은 권장이며 후행 채점에 반영된다. 첨부는 선택(최대 10개·합계 8MB), 별도 PDF는 필수가 아니다.

인증 시험 근거는 합성 계정의 실제 성공/거절 요청·응답을 나란히 남겼으며 비밀번호/cookie/token/CSRF는 가렸다. 운영 첫 가입 503과 공유 횟수 제한/검사 스크립트 실패도 성공으로 바꾸지 않는다. 최신 반복의 계정 setup은 별도 합성 bucket을 사용하는 서버 fixture이며 공개 가입 폼은 production-browser.json에 실제 확인했다.

실제 T06 이관은 actual-migration.json에 7표 건수·전체 값 digest만 공개한다. 원본과 본인 export는 .test-data에 비공개 보관하고 실제 계정 식별자는 공개 보고서에서 제외한다. 실제 관찰은 질문/첫 규칙/계산, 날짜별 할 일/완료, 변경 시각·이유·1~2일차 참조, 직접 합계/평균과 전후 비교, 최종 전체 파일 하나를 남긴다. 아직 실제 날짜 확정은 0일이다. 본인 비밀번호를 심사자에게 보내지 않는다.

## 로컬과 비밀번호 길이

로컬은 개발/기록에 쓸 수 있으나 제출은 공개 HTTPS와 공개 소스를 요구한다. 로컬 DB와 공개 DB는 자동 동기화하지 않는다. 실제 이관과 앞으로의 관찰은 공개 앱에서 진행한다.

12자는 과제 공식 조건이 아닌 AI 정책이다. 사용자 질문만으로 길이를 변경하지 않았다. 공백은 보존하고 문자 조합을 강제하지 않는다. 2026-10-02 원문 확인한 [NIST SP 800-63B-4 §3.1.1.2](https://pages.nist.gov/800-63-4/sp800-63b.html#passwordver)는 단독 비밀번호 최소 15자/MFA 일부 최소 8자를 요구한다. 현재 MFA 없음·12자로 해당 NIST 길이 준수를 주장하지 않는다.
