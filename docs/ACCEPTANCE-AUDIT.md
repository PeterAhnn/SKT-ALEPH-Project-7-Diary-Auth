# T07 충족 여부 점검 · 2026-10-02

**현재 전체 충족은 아니다.** 로컬 구현과 합성 검사는 통과했지만 공개 운영·실제 T06 이관·실제 5일 기록·최종 제출 근거가 남았다. 검사 45개 통과는 공식 68개 기준 전체 통과와 다른 수량이다.

원문은 오늘 실제 로그인된 안내에서 보존한 [TASK-SOURCE.md](./TASK-SOURCE.md), 전체 단계별 첫 행동·통과 기준·막힐 때 순서·남길 것은 [TASK-READBACK.md](./TASK-READBACK.md)다. 이번 점검은 그 원문과 현재 코드·검사 파일·설명서·제출 초안을 대조했다. 플랫폼 페이지를 새로 읽거나 운영 배포 검사를 새로 실행한 결과는 아니다. 항목별 근거와 남은 확인은 [acceptance-audit.json](../verification/acceptance-audit.json)에 기록한다.

## 로컬 사용과 제출

로컬은 개발·시험과 실제 기록 입력에 쓸 수 있다. 공식 원문은 실제 5일에 특정 호스팅 서비스를 지정하지 않는다. 다만 제출 화면은 **공개 결과물 URL과 공개 full commit HTTPS 소스 URL**을 요구하므로 localhost만으로 최종 제출 기준을 충족하지 못한다. 로그인 첫 화면까지는 가입 없이 열리고, 개인 자료는 인증 뒤에만 보여야 한다.

로컬 계정·DB는 미래 공개 계정·DB와 자동 동기화되지 않는다. 아직 그 연결을 구현·검증하지 않았다. 중복 입력과 관찰 자료 재이관을 피하려면 **공개 운영 준비 → 운영 검사 → 본인 계정/T06 이관 → 실제 5일** 순서가 적절하다. 이는 작업 순서 제안이며 공식에 없는 ‘로컬 관찰 금지’ 조건을 추가하는 것이 아니다. 앞서 로컬 가입을 바로 다음 필수 행동처럼 안내한 표현은 이 구분을 충분히 설명하지 못했다.

## 비밀번호 길이

공식 과제는 최소 12자를 요구하지 않는다. 12자는 AI가 추가한 현재 앱 정책이며 해시·salt·원문 미노출 검증과 별개다. 서버와 가입/변경 화면이 모두 12자를 검사한다. 길이 정책은 이번 질문만으로 변경하지 않았다. 공백을 포함한 여러 단어를 사용할 수 있으며 대문자·숫자·특수문자 조합을 강제하지 않는다.

현재 [NIST SP 800-63B-4 §3.1.1.2](https://pages.nist.gov/800-63-4/sp800-63b.html#passwordver)는 비밀번호만으로 인증하는 경우 최소 15자, 다중 인증의 일부인 경우 최소 8자를 요구한다. 2026-10-02 격리된 gstack `/browse`에서 원문을 확인했다. 현재 앱은 MFA가 없고 12자이므로 이 NIST 길이 조건을 충족했다고 주장하지 않는다. 과제 조건·현재 구현 정책·외부 보안 기준을 구분한다.

## 확인 일정

1. **지금:** 원문 68개와 구현·근거·제출 초안 연결, 없는 근거는 미완료로 표시한다. 이번 점검이 해당한다.
2. **공개 배포 직후:** 시크릿 공개 접근, 두 시험 계정의 인증·소유자 거절·변경 전후 불변, 로그/응답/세션을 운영 환경에서 확인한다. 본인 자료를 넣기 전에 수행한다.
3. **실제 이관 직후·1일차:** 현재 T06 전체 자료가 본인 계정으로 보존됐는지 대조하고 새 관찰의 질문·지표·단위·계산·첫 규칙을 고정한다.
4. **2일차 뒤·3일차 전:** 실제 두 날을 참조하는 한 번의 규칙 변경 시각·이유·순서를 확인한다.
5. **5일차 뒤:** 실제 날짜 정확히 5개, 같은 계산, 전후 비교·손계산·전체 export를 대조한다.
6. **제출 직전:** 1~5단계·완주 체크리스트·제출 항목·보관 근거를 전부 다시 확인한다. 공개 full commit·설명/코드/응답 일치·가림·파일 수/용량까지 점검하고 미완료가 남으면 표시한다. 제출 접수와 강사/마스터 승인도 별도로 기록한다.
