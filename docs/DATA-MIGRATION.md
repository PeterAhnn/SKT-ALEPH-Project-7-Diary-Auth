## 실제 이관 순서

1. 사용자가 T07 본인 계정에 가입·로그인한다. 아직 자료가 없는 계정이어야 한다. 비밀번호를 채팅이나 보고서에 적지 않는다.
2. `T06 자료 가져오기`에서 위 원본 파일을 선택하고 미리보기의 7표 건수와 digest를 대조한 뒤 가져오기를 실행한다. 대상 계정은 서버가 로그인한 계정으로만 정한다.
3. 본인 계정에서 전체 내보내기를 수행한다. 내보낸 파일의 기존 7표 digest·모든 행 값을 원본과 대조하고 이관 영수증을 확인한다. 본인 계정의 계획·할 일 화면도 확인한다. 원본 파일은 보존한다.

업로드 후 자료가 바뀌거나 대상 계정이 비어 있지 않으면 거절한다. 중간 삽입 실패 시 앞서 들어간 행과 영수증까지 모두 되돌린다. ID·시간·이력·회고 관계를 유지한다. 합성 검사에서 성공·거절·롤백과 화면 업로드를 검증했다. 실제 본인 계정으로 UI 가져오기를 완료하고 전체 export를 다운로드해 7표 건수와 모든 값의 canonical digest 일치를 확인했다. actual-migration.json에는 가린 대조 근거만 공개하고 raw export는 .test-data/user-evidence에 보관한다.

## 관찰과의 연결

이관한 과거 기록은 5일 관찰 값으로 사용하지 않는다. 새 ALEPH 계획의 `5일` 탭에서 실제 질문·첫 규칙을 정하고 계산 기준에 동의한 뒤 시작한다. 지표는 사용자가 선택한 `완료한 할 일 수(개)`이며 실제 관찰 날짜와 판단은 사람이 남긴다. 자세한 순서는 [관찰 계획](./OBSERVATION-PLAN.md)에 있다.
