## 실행

Node.js 24에서 외부 패키지 설치 없이 실행합니다.

```powershell
npm start
```

주소: http://127.0.0.1:8006. 실제 자료는 서버의 `.data/diary.sqlite`에 저장됩니다. 브라우저 저장소에 의존하지 않습니다. 처음에는 빈 다이어리입니다.

필요하면 `.env.example`을 `.env`로 복사합니다. 로컬 SQLite 대신 준비된 Supabase DB를 사용하려면 서버 환경에 `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`를 설정합니다. 공개 DB 생성·스키마 적용·배포 상태는 검증 보고서를 확인하세요. 비밀키나 service-role 키를 사용하지 않습니다.

## 사용

1. 계획을 만들고 기간·성공 기준·예상 분을 입력합니다. 계획 수정은 같은 ID의 새 버전으로 저장되며 이전 이력은 유지됩니다.
2. 할 일을 추가하고 완료·다시 열기·실행 기록을 남깁니다. 실제 시간을 적어도 예상 시간은 그대로입니다. 삭제한 할 일은 복구할 수 있습니다.
3. 돌아보기에서 숫자를 눌러 계산에 기여한 기록을 확인합니다. 개선 한 줄을 저장하고 다음 계획에 연결합니다. ‘전체 내보내기’는 연결 자료와 이력을 JSON 파일 하나로 저장합니다.

서울 날짜를 기준으로 지연을 판단하며, 시간 단위는 분입니다. ‘계획 수’는 선택한 계획에 연결된 삭제되지 않은 **할 일 수**입니다. 현재 완료 상태만 완료로 세고, 막힘은 이유가 있는 할 일마다 한 번 셉니다. 예상은 할 일 예상 시간의 합, 실제는 연결된 실행 시간의 합, 차이는 실제−예상입니다. 빈 합계는 0입니다.
